# Rules

Coding standards for the Sessions Portal backend (Django 4.2 + DRF, apps `events` and `users`).
`CLAUDE.md` at the repo root covers commands and architecture; these files cover how to write and review changes.

| File | Scope |
|------|-------|
| `backend-django.md` | Views, serializers, models, queries, migrations, Celery |
| `backend-python.md` | Pylint/pycodestyle standards, naming, error handling, logging |
| `solid.md` | SOLID principles applied to Django + DRF |
| `security.md` | Secrets, input validation, permissions, high-scrutiny surfaces |
| `testing.md` | pytest layout, fixtures, coverage gate |
| `branching.md` | Branching, commit messages, pull request expectations |
